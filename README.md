# Análisis de eclipses solares y salud ocular

## Descripción

Este proyecto analiza la posible relación entre los eclipses solares y la salud ocular a partir de diferentes estudios y datos relacionados con la retinopatía solar, la asistencia a urgencias y la prevención de lesiones oculares.

El análisis se ha realizado mediante Python, utilizando Pandas para la organización y exploración de los datos, y Matplotlib y Plotly para su visualización. Además, se ha utilizado Dash para la creación de un dashboard interactivo que permite presentar los principales resultados del análisis.

## Objetivos

- Explorar datos relacionados con la salud ocular durante períodos con y sin eclipses.
- Comparar la frecuencia de casos de retinopatía solar.
- Analizar la asistencia a urgencias antes y después de un eclipse.
- Examinar la presencia de recomendaciones sobre protección ocular en los medios analizados.
- Representar los principales resultados mediante gráficos interactivos.
- Crear un dashboard interactivo con Dash.

## Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Dash
- Jupyter Notebook

## Principales resultados

El análisis mostró una media de 51,5 casos en los años con eclipse frente a 37,3 casos en los años sin eclipse, lo que supone una diferencia de 14,2 casos.

Además, el 93,5 % de los periódicos analizados mencionaron el uso de gafas de protección para eclipses.

Los resultados deben interpretarse teniendo en cuenta que los datos proceden de estudios con características diferentes y que el análisis no permite establecer relaciones causales.

## Visualización interactiva

El proyecto incluye un dashboard desarrollado con Dash que reúne los principales gráficos obtenidos durante el análisis y permite visualizar los resultados de forma interactiva.

## Conclusiones

Los datos analizados muestran una mayor frecuencia de casos de retinopatía solar en los años con eclipse respecto a los años sin eclipse, además de una elevada presencia de recomendaciones sobre protección ocular en los medios estudiados.

Este proyecto muestra cómo las herramientas de análisis y visualización de datos pueden utilizarse para explorar cuestiones relacionadas con la salud ocular y transformar datos procedentes de diferentes fuentes en información visual y comprensible.
